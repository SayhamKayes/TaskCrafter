# TaskCrafter

A modern, comprehensive web utility application designed to streamline productivity and manage daily tasks efficiently. 

**[Live Demo](https://sayhamkayes.github.io/TaskCrafter/)**

## 🚀 Features

* **Dashboard Overview:** A centralized hub to monitor your daily activities and quick stats.
* **Task Management:** Create, organize, and track your to-dos with ease.
* **Notes:** Built-in note-taking functionality to capture ideas and important information on the fly.
* **Timer:** Integrated timer to help with time management and focus sessions.
* **Calculator:** A handy quick-access calculator for everyday computations.
* **Salah Times:** Stay updated with accurate prayer times directly within your workspace.
* **Invoice Generator:** Easily create and manage professional invoices.

## 🛠️ Tech Stack

This project is built using modern web development tools:

* **[React](https://react.dev/)** - UI Library
* **[TypeScript](https://www.typescriptlang.org/)** - Static typing for scalable and robust code
* **[Vite](https://vitejs.dev/)** - Next-generation frontend tooling for blazing fast builds
* **[Tailwind CSS](https://tailwindcss.com/)** - Utility-first CSS framework for rapid styling
* **[shadcn/ui](https://ui.shadcn.com/)** - Reusable and accessible UI components

## 📦 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository
   ```sh
   git clone https://github.com/SayhamKayes/TaskCrafter.git

2. Navigate to the project directory

   ```sh
   cd TaskCrafter

3. Install NPM packages

   ```sh
   npm install

4. Start the development server

   ```sh
   npm run dev

🏗️ Building for Production

1. To create a production build, run:

   ```sh
   npm run build

2. To preview the production build locally:

   ```sh
   npm run preview
